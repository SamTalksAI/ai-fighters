# AI Fighters

A retro 2D arcade fighting game prototype in the browser: a parody of tech CEOs in the AI race. Created by [@SamTalksAI](https://x.com/SamTalksAI).

[Play](https://samtalksai.github.io/ai-fighters/)

## Controls

**Keyboard:** arrows/WASD move-jump-crouch, J punch, K kick, L block, I special, M mute, P / Esc pause

**Mobile:** on-screen D-pad and PUNCH/KICK/BLK/SP buttons

A parody game. Not affiliated with any real person or company.
